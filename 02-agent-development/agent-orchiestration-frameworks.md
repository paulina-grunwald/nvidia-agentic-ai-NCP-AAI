# Overview

Agent orchestration frameworks help you build systems where one or more AI agents work together to accomplish tasks. Each framework has a different approach.

---

# Quick Comparison

| Framework | Creator | Primary Focus | Think of it as... |
| --- | --- | --- | --- |
| **AutoGen** | Microsoft | Multi-agent conversations | Agents in a group chat 💬 |
| **LangGraph** | LangChain | Stateful workflow graphs | Agents as a flowchart 📊 |
| **CrewAI** | CrewAI | Role-based agent teams | Agents with job titles 👔 |
| **LangChain** | LangChain | Chains and tools | Single agent + tools 🔧 |
| **LlamaIndex** | LlamaIndex | Data/RAG focused | Agent + data retrieval 📚 |
| **NeMo Agents** | NVIDIA | Enterprise orchestration | NVIDIA-native solution ✅ |
